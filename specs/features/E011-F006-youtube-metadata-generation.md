## Task Description

Automatically generates a YouTube-optimized title, description, and tags based on the video content. The system produces a 150-300 word SEO-optimized description, 10-15 relevant tags, and optional chapter timestamps derived from the outline. All fields are editable by the user and have one-click copy buttons.

**What it does**: Automatically generates a YouTube-optimized title, description, and tags based on the video content.

**Expected outcome**: The system produces a 150-300 word SEO-optimized description, 10-15 relevant tags, and optional chapter timestamps derived from the outline. All fields are editable by the user and have one-click copy buttons.

This feature generates YouTube metadata (description, tags, timestamps) using AI, based on the video's approved script, title, outline, and topic. The metadata is generated automatically when the user reaches this step, stored on the video, and presented in an editable form with copy-to-clipboard functionality.

The YouTube title is the already-selected video title from E009-F004. The AI generates the description, tags, and chapter timestamps.

## Objective

Create a YouTube metadata generation pipeline: a `MetadataGenerationService` that generates SEO-optimized descriptions, tags, and chapter timestamps from the video content; a `GenerateMetadataJob` for async processing; database columns for storing metadata; a controller and frontend page showing editable metadata fields with one-click copy buttons. The metadata auto-generates when the user reaches this step.

### MetadataGenerationService

Create `app/Services/MetadataGenerationService.php`:

```php
class MetadataGenerationService
{
    public function __construct(private AiClient $aiClient) {}

    public function generate(Video $video): array
    {
        // Use the same model as title generation (metadata is a similar task)
        $modelKey = $video->getModelForStep('title');
        $systemPrompt = $this->buildSystemPrompt();
        $userPrompt = $this->buildUserPrompt($video);
        $response = $this->aiClient->generate($modelKey, $systemPrompt, $userPrompt, 4096);
        return $this->parseResponse($response, $video);
    }
}
```

The system prompt instructs the AI to:

- Generate a YouTube video description (150-300 words) that is SEO-optimized
- Include: an engaging hook paragraph, content summary, key takeaways, and a call to action
- Generate 10-15 relevant tags as an array of strings (no hashtags, just keywords)
- Tags should include: primary topic keywords, related topics, long-tail variations, and trending terms
- Respond in valid JSON with `description` (string) and `tags` (string array)

The chapter timestamps are NOT generated by AI. Instead, they are automatically derived from the approved outline's section titles and duration estimates:

```php
private function generateChapters(Video $video): array
{
    $outline = $video->generated_outline;
    $chapters = [];
    $currentSeconds = 0;

    // Hook
    $chapters[] = [
        'timestamp' => $this->formatTimestamp($currentSeconds),
        'title' => $outline['hook']['title'],
    ];
    $currentSeconds += $outline['hook']['duration_seconds'];

    // Main sections
    foreach ($outline['sections'] as $section) {
        $chapters[] = [
            'timestamp' => $this->formatTimestamp($currentSeconds),
            'title' => $section['title'],
        ];
        $currentSeconds += $section['duration_seconds'];
    }

    // Closing
    $chapters[] = [
        'timestamp' => $this->formatTimestamp($currentSeconds),
        'title' => $outline['closing']['title'],
    ];

    return $chapters;
}

private function formatTimestamp(int $seconds): string
{
    $minutes = intdiv($seconds, 60);
    $secs = $seconds % 60;
    return sprintf('%d:%02d', $minutes, $secs);
}
```

### GenerateMetadataJob

```php
class GenerateMetadataJob implements ShouldQueue
{
    use Queueable;

    public function __construct(public Video $video) {}

    public function handle(MetadataGenerationService $service): void
    {
        $this->video->update(['status' => 'generating_metadata']);

        try {
            $metadata = $service->generate($this->video);
            $this->video->update([
                'youtube_metadata' => $metadata,
                'status' => 'metadata_generated',
            ]);
        } catch (\Throwable $e) {
            $this->video->update([
                'status' => 'metadata_generation_failed',
                'generation_error' => $e->getMessage(),
            ]);
            throw $e;
        }
    }
}
```

### MetadataController

```php
class MetadataController extends Controller
{
    public function index(Video $video): Response
    {
        abort_unless($video->user_id === auth()->id(), 403);

        return Inertia::render('videos/metadata', [
            'video' => $video->only([
                'id', 'selected_title', 'status', 'youtube_metadata', 'generation_error',
            ]),
        ]);
    }

    public function generate(Video $video): RedirectResponse
    {
        abort_unless($video->user_id === auth()->id(), 403);

        GenerateMetadataJob::dispatch($video);

        return to_route('videos.metadata', $video);
    }

    public function update(UpdateMetadataRequest $request, Video $video): RedirectResponse
    {
        abort_unless($video->user_id === auth()->id(), 403);

        $video->update([
            'youtube_metadata' => $request->validated()['metadata'],
            'status' => 'metadata_approved',
        ]);

        return to_route('videos.create.step', [
            'video' => $video,
            'step' => 'voiceover-selection',
        ]);
    }
}
```

### Tag Editor

The tag editor allows adding, removing, and editing tags:

```tsx
function TagEditor({ tags, onChange }: TagEditorProps) {
    const [newTag, setNewTag] = useState('');

    const addTag = () => {
        if (newTag.trim() && !tags.includes(newTag.trim())) {
            onChange([...tags, newTag.trim()]);
            setNewTag('');
        }
    };

    const removeTag = (index: number) => {
        onChange(tags.filter((_, i) => i !== index));
    };

    return (
        <div className="space-y-2">
            <div className="flex flex-wrap gap-2">
                {tags.map((tag, index) => (
                    <Badge key={index} variant="secondary" className="gap-1">
                        {tag}
                        <button onClick={() => removeTag(index)}>
                            <X className="h-3 w-3" />
                        </button>
                    </Badge>
                ))}
            </div>
            <div className="flex gap-2">
                <Input
                    value={newTag}
                    onChange={(e) => setNewTag(e.target.value)}
                    onKeyDown={(e) =>
                        e.key === 'Enter' && (e.preventDefault(), addTag())
                    }
                    placeholder="Add a tag..."
                    className="h-8 text-sm"
                />
                <Button variant="outline" size="sm" onClick={addTag}>
                    Add
                </Button>
            </div>
        </div>
    );
}
```

## Notes

- Chapter timestamps are deterministically derived from the outline, not AI-generated. This ensures they are accurate and consistent with the actual video structure. The AI only generates the description and tags.
- The metadata generation reuses the 'title' model from AI config since metadata generation is a similar lightweight task. There's no dedicated 'metadata' step in `config/ai.php`.
- YouTube descriptions have a 5,000 character limit. The 150-300 word target keeps it well within this limit while being substantial enough for SEO.
- Tags in YouTube are comma-separated keywords. The copy function formats them as `tag1, tag2, tag3` for easy pasting into YouTube Studio.
- Chapter timestamps in YouTube must start with `0:00` to be recognized. The service ensures the first chapter always starts at `0:00`.
- The `useClipboard` hook already exists in the codebase. It handles the clipboard API with fallback support.
- The metadata page serves double duty: it generates metadata AND allows editing before saving. The auto-start behavior means the user doesn't need to click "Generate" -- it happens automatically when they arrive at this step.
